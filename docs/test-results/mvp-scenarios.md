### 0.2 実施方法・結果の凡例

実施方法：
- **動画確認**：既存の動画で、手順と期待結果が映っていることを確認した。動画の名前・撮影日・コミットを書く。撮影後に関係する変更があれば、「再確認」と書く
- **共同確認（画面）**＝分類1：めぐさんの環境で、実画面を共同で確認した
- **共同確認（停止・設定変更）**＝分類2：API・DB・Redis などを停止、または設定を変えて確認した
- **自動テスト結果**＝分類3：モックまたは自動テストの結果を使った（1.1の証跡を参照）
- 「（補足：自動テスト）」は、実画面などで確認する項目に、自動テストの結果を補足の証跡として添えること

結果：**OK** / **NG**（不具合として切り分け） / **既知の制約**（失敗と区別する。3節に根拠を書く） / **未実施**（依存Issueや環境待ちなど。理由を備考へ）

「実施者・証跡」には、操作した人と、動画名・スクリーンショット・コミットなどを書く。内容（入力文、鍵、トークン）は書かない。
