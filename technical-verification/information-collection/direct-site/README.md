# 公式サイトから直接取得する方法

担当：もえさん

## 目的

Snow Man公式INFOページの一覧から、最新5件の公開日・タイトル・URLを直接取得できるか確認する。

## 調査項目

- 公式APIが提供されているか
- RSSが提供されているか
- 利用規約・サイトポリシーに自動取得に関する記載があるか
- `robots.txt`に対象ページへのアクセスに関する記載があるか
- 一覧ページのHTMLに公開日・タイトル・URLが含まれているか
- JavaScriptによる追加表示が必要か

## 進め方

1. まずブラウザ上で上記の調査項目を確認する。
2. 判断できない点をメモする。
3. 実行して問題ないと判断できた場合だけ、一覧ページへ1回リクエストする。
4. 最新5件の公開日・タイトル・URLを抽出する。
5. 実行結果を`result.json`へ記録する。

## 完了条件

次のいずれかを説明できれば完了とする。

- 最新5件の3項目を取得できた。
- 一部の項目だけ取得できた。
- 技術的な理由により取得できなかった。
- 規約上の懸念があり、プログラムによる取得を見送った。

## 注意事項

- 対象は一覧ページのみとし、個別記事本文にはアクセスしない。
- 同時リクエストは行わない。
- 短時間に繰り返し実行しない。
